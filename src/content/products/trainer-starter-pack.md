## What's in the box

| Component | Qty | Purpose |
|-----------|-----|---------|
| ESP32 dev board | 1 | The brain of every kit |
| Breadboard (full-size) | 1 | Solderless prototyping |
| Jumper wire kit (M-M, M-F, F-F) | 1 set | Connecting components |
| USB-C cable | 1 | Power + programming |
| LEDs (red, blue, green) | 3 | Visual output |
| Tactile push buttons | 3 | User input |
| Piezo buzzer | 1 | Audio output |
| Resistors (220Ω, 1kΩ, 10kΩ) | 10 | Current limiting + pull-ups |

## What you'll learn

- **Blink an LED** — the first thing every electronics hobbyist does
- **Read a button** — digital input and debouncing
- **Play tones** — PWM audio with the buzzer
- **WiFi basics** — connect your ESP32 to the internet
- **Arduino IDE** — install it, flash code, debug

## Requirements

- A computer with USB port (Windows, Mac, or Linux)
- Arduino IDE installed (guide included)
- No soldering needed

## Difficulty

**Beginner** — first-time friendly, 1-2 hours to complete all exercises.

## After this kit

Once you've built everything in the Starter Pack, you're ready for the Theme Kits. Each one reuses your ESP32, breadboard, and wires — just add the new component and follow the guide.
