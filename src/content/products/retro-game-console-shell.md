**Requires:** Starter Pack (ESP32, breadboard, wires, USB-C cable, buttons, buzzer)

## What you'll learn

- **Game logic** — loops, input, scoring, win conditions
- **OLED rendering** — drawing sprites, text, and frames
- **Collision detection** — objects hitting walls and each other
- **Input handling** — reading D-pad and button presses
- **State management** — menus, playing, game over screens

## Difficulty

**Intermediate** — game code is more involved, 2 hours to build + code.

## After this kit

Combine with the Pokéball Signal Tower to build a Game Boy Color — add LED backlighting to the retro console.
