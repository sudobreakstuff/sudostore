  send you a notification if connected to WiFi. All housed in a
  3D-printed pot-station that sits next to your plant.

  - ESP32 dev board — programmed and ready
  - Capacitive soil moisture sensor — no corrosion
  - 0.96" OLED display — live readings
  - 3D-printed pot-station — designed to sit next to a plant
  - All wires and a USB-C cable
  - Complete build guide with wiring diagrams and code

  Monitor one plant or many — add a second sensor and a second
  OLED for a multi-plant dashboard. The code supports up to 4 sensors.
