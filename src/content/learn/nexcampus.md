Want to learn coding and study without needing an internet connection? **NexCampus**
is a free, offline student toolkit I built — it runs entirely in your browser
and works with zero internet once loaded.

> Open it here: **[sudobreakstuff.github.io/Nexcampus](https://sudobreakstuff.github.io/Nexcampus/)**

## What's inside

- **Code Lab** — write and run Python, JavaScript and Bash right in the browser
- **Dictionary** — a 262,000-word dictionary, no signal required
- **Flashcards** — build your own decks and drill them
- **Periodic table** — interactive, great for chemistry
- **Text tools** — utilities that save time on study notes
- **Solar system** — a quick interactive reference
- **OCR** — pull text out of images
- **Nine themes** — make it look the way you like

## Why it's a great first tool

If you're just starting to code, the Code Lab is the fastest way to experiment:
no installs, no setup — type a line, run it, break it, fix it. Combine it with
the Python guide on this site and you've got a complete beginner setup that
works even on an old laptop with no data.
